# Changelog

## 0.3.3

* Reorder the status columns by dragging the status list. The order is saved with the shortcut.
* Search the cards by issue number, subject, assignee, assigner, tracker, priority or version.
* Show who assigned the current assignee on each card.

## 0.3.2

* List the same assignees as the issue form, including every assignable user and group, and keep search.

## 0.3.1

* Show the status-change fields in a dialog that stays above the board.
* Search the assignee list.
* Add files to the note. They are stored on the issue with that update.

## 0.3.0

* Add a switch that asks for assignee, notes, dates and done ratio before a status change.
* Leave the switch off to change the status directly.

## 0.2.0

* Filter the board by one or more saved issue queries.
* Choose which statuses are shown.
* Save a board as a shortcut, then edit, update or delete it.
* Share a shortcut privately, with everyone, or with selected roles, including the option for all projects.

## 0.1.0

* Add a Kanban project tab beside Issues.
* Show issues in status columns, with filters and drag-and-drop status changes that follow the workflow.
